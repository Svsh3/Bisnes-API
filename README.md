# 🤖 TG Business AutoResponder

Автоответчик через **Telegram Business Bot API**.  
Отвечает за тебя когда ты офлайн. ИИ через OpenRouter, история чатов, панель настроек.

---

## ⚡ Быстрый старт — GitHub + Bothost

### 1. Форкни или залей репозиторий на GitHub

```bash
git clone https://github.com/ВАШ_НИК/tg_autoresponder
cd tg_autoresponder
git init
git add .
git commit -m "init"
git remote add origin https://github.com/ВАШ_НИК/tg_autoresponder.git
git push -u origin main
```

---

### 2. Получи токены

| Что | Где взять |
|---|---|
| `BOT_TOKEN` | @BotFather → `/newbot` |
| `OWNER_ID` | Напиши @userinfobot — он пришлёт твой ID |
| `OPENROUTER_API_KEY` | https://openrouter.ai/keys → Create Key |

---

### 3. Зарегистрируйся на Bothost

Сайт: **https://bothost.ru** → Регистрация → тариф **Basic (99₽/мес)**  
*(на бесплатном тарифе нет переменных окружения — бот не запустится)*

---

### 4. Создай проект на Bothost

1. Панель → **Создать бота**
2. Тип: **Telegram**, язык: **Python**
3. Способ деплоя: **GitHub**
4. Подключи свой репозиторий

---

### 5. Добавь переменные окружения

В панели Bothost → раздел **Env Variables** → добавь:

```
BOT_TOKEN        =  токен_от_BotFather
OWNER_ID         =  твой_telegram_id
OPENROUTER_API_KEY = sk-or-v1-...
```

Опционально:
```
OFFLINE_THRESHOLD = 120   # секунд до авто-ответа (по умолчанию 120 = 2 минуты)
```

---

### 6. Деплой

Нажми **Deploy / Старт** в панели Bothost.  
Через 2–5 минут в логах появится:

```
✅ База данных инициализирована
🚀 Бот запущен. Владелец ID: 123456789
```

---

### 7. Включи Business Mode в Telegram

1. **@BotFather** → `/mybots` → твой бот → **Bot Settings → Business Mode → Enable**
2. Telegram → **Настройки → Telegram Business → Чат-боты** → выбери бота → включи **«Отвечать на сообщения»**

---

### 8. Готово — проверка

Напиши своему боту `/start` в личном чате — откроется панель управления.  
Попроси кого-нибудь написать тебе → подожди 2 минуты без активности → бот ответит автоматически.

## 🎛 Панель управления (команда /start)

| Кнопка | Что делает |
|---|---|
| 🟢/🔴 Включить/Выключить | Включить или отключить авто-ответы |
| 📍 Установить статус | Задать текст «куда ушёл» — бот будет отвечать по нему |
| 🤖 Сменить модель | GPT-4o, Claude, Gemini, DeepSeek и др. |
| ✏️ Промт бота | Свои инструкции поверх базового |
| 🏷 Имя бота | Поменять имя автоответчика |
| 🗑 Очистить историю | Сбросить историю всех диалогов |
| 📊 Настройки | Посмотреть текущие параметры |

---

## 📍 Статус

Установи статус — например:
> `ушёл по делам, вернусь вечером`

Если кто-то спросит «где ты?» или «пойдёшь гулять?» — бот ответит именно по этому тексту.  
Сбросить статус: напиши `0`.

## 🔒 Безопасность

- Панель настроек доступна **только тебе** (проверка по `OWNER_ID`)
- `.env` добавлен в `.gitignore` — случайно не запушишь токены
- Конфиденциальные данные прописаны в промте как запрещённые к разглашению

## ❗ Частые проблемы

| Проблема | Решение |
|---|---|
| `EnvironmentError: BOT_TOKEN не задан` | Проверь Env Variables в панели Bothost |
| `ModuleNotFoundError` | Убедись что `requirements.txt` в корне репо |
| Бот не отвечает через Business | Включи Business Mode в @BotFather |
| Бот отвечает хотя ты онлайн | Напиши боту любое сообщение — он обновит `last_seen` |
